🚀 How to Publish This Frontend to GitHub Pages

Completely decoupled static deployment instructions

Because this frontend is 100% static (HTML, Vanilla CSS, JS) and decoupled from the backend, you can publish the sample_vulnerable_app/frontend/ directory directly to GitHub Pages or Netlify / Vercel!

1. Configure the API URL

Before or after publishing, simply edit frontend/config.json: 

{
  "api_url": "https://your-live-backend-url.com"
}

Anyone visiting your GitHub Pages site will automatically connect to that API endpoint. Users can also change the API URL on the fly using the input bar at the top!

2. Publishing to GitHub Pages

  1. Push this repo or copy the frontend/ files to a new GitHub repository (e.g. vulnerable-security-lab-ui).
  2. In GitHub repo settings → Pages → Select Branch: main → Save.
  3. Your lab frontend is live at https://<your-username>.github.io/<repo-name>/!

3. Running the Backend

Run the backend locally on port 8001: 

cd sample_vulnerable_app/backend
python -m uvicorn app:app --port 8001 --reload

CORS is pre-configured with allow_origins=["*"] so the GitHub Pages frontend can connect seamlessly to your backend or ngrok/cloud tunnel URL.
