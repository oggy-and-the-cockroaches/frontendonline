🛡️ AI Fix: Prepared statements & bcrypt password hashing.
INJECTION 03 CWE-79 • High

🛡️ AI Fix: Context-aware HTML escaping & CSP enforcement.
INJECTION 04 CWE-79 • Medium
HTML Injection
Untrusted markup tags (iframes, embedded objects, spoofed forms) reflected into web responses to phish credentials.
<iframe <object <embed <form <svg
🛡️ AI Fix: DOM textContent assignment & frame sandboxing.
INJECTION 05 CWE-1336 • Critical
Server-Side Template (SSTI)
Attacker expressions breaking out of template engines (Jinja2, Twig, Mako) to invoke system objects and escape sandboxes.
{{...}} ${...} <%=...%> __class__.__mro__
🛡️ AI Fix: Safe template context passing without string rendering.
INJECTION 06 CWE-97 • High
Server-Side Includes (SSI)
Directives that trick legacy web servers and preprocessors into executing arbitrary shell scripts on the host server.
<!--#exec <!--#include <!--#echo <!--#config
🛡️ AI Fix: Disabling server execution flags & input sanitization.
INJECTION 07 CWE-643 • High
XPath Injection
Syntax manipulation in XML database query paths allowing attackers to navigate unauthorized XML data trees.
//*[ ]|// ' or '1'='1 /parent::*
🛡️ AI Fix: Parameterized XPath variables & schema validation.
INJECTION 08 CWE-90 • High
LDAP Injection
Filter metacharacter injections that manipulate corporate directory lookups, bypassing enterprise single sign-on.
)(| )(& *(| null byte
🛡️ AI Fix: RFC 4515 LDAP query encoding & search filters.
INJECTION 09 CWE-611 • Critical
XML Entity Injection (XXE)
Malicious external entity declarations that force XML parsers to disclose local files, internal SSRF ports, or trigger DoS.
<!DOCTYPE <!ENTITY SYSTEM <!ENTITY PUBLIC
🛡️ AI Fix: Disabling resolve_entities and DTD processing.
INJECTION 10 CWE-78 • Critical
OS Command Injection
Command concatenation operators that execute host discovery and reconnaissance commands via vulnerable system calls.
; whoami && whoami | whoami ; id ; dir
🛡️ AI Fix: Executing commands with array arguments without shell=True.
INJECTION 11 CWE-94 • Critical
Remote Code Execution (RCE)
Direct invocation of shell interpreters, reverse shells, or remote downloaders (curl, wget) that take over the entire server.
/bin/sh /bin/bash powershell cmd.exe curl http://
🛡️ AI Fix: Removing dynamic code evaluation and system popens.
INJECTION 12 CWE-113 • High
CRLF / Response Splitting
Carriage return and line feed character injection used to smuggle malicious HTTP headers, set forged cookies, or poison caches.
\r\n \nSet-Cookie: \r\nLocation:
🛡️ AI Fix: Stripping newline characters before writing response headers.
INJECTION 13 CWE-22 • High
Path Traversal & LFI
Dot-dot-slash sequence payloads that escape designated web directories to read sensitive host files like /etc/passwd or win.ini.
../ ..\\ /etc/passwd C:\\windows\\win.ini ..%2f..%2f
🛡️ AI Fix: Canonical path verification via os.path.realpath().
